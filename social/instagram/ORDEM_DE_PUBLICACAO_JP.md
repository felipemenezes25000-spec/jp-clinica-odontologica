# JP Clínica Odontológica — Ordem de Publicação

Este arquivo define **somente**:

- a ordem das publicações;
- o nome das pastas;
- o que deve existir dentro de cada pasta;
- o dia em que cada conteúdo deve ser publicado;
- quais posts devem ser fixados;
- a ordem dos Destaques.

Não inclui automação, n8n, Metricool, JSON ou qualquer outra ferramenta.

# 3. O que deve existir dentro de cada tipo de pasta

## Reel

```text
01_REEL_Conheca-a-JP/
├── VIDEO.mp4
├── CAPA.png
└── LEGENDA.txt
```

Publicar:

- `VIDEO.mp4` como Reel;
- usar `CAPA.png` como capa do Reel;
- copiar o conteúdo de `LEGENDA.txt` para a legenda.

**Não publicar a capa como post separado.**

---

## Carrossel

```text
02_CARROSSEL_Implantes-na-JP/
├── 01.png
├── 02.png
├── 03.png
├── 04.png
├── 05.png
├── 06.png
├── 07.png
└── LEGENDA.txt
```

Publicar todos os slides **na ordem numérica**:

```text
01.png
02.png
03.png
04.png
...
```

Depois usar `LEGENDA.txt` como legenda do carrossel.

---

## Post estático

```text
05_POST_Aqui-comeca-o-cuidado/
├── POST.png
└── LEGENDA.txt
```

Publicar:

- `POST.png`;
- legenda de `LEGENDA.txt`.

---

## Card da equipe

```text
10_POST_Equipe-Ana-Beatriz/
├── POST.png
└── LEGENDA.txt
```

Mesmo funcionamento de um post normal.

# 7. Stories

Stories não entram na sequência `01 → 22` do feed.

Eles podem acompanhar as publicações.

Regra simples:

- publicou Reel → depois pode postar Story chamando para o Reel;
- publicou carrossel → depois pode postar Story chamando para o carrossel;
- nos outros dias → usar bastidor, avaliação, equipe, localização ou dica.

A capa de Destaque também **não é publicação de feed**.
